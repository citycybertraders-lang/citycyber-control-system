# CityCyber Control System

High-control POS system with pricing intelligence, udhaar (credit) ledger, and cashflow tracking.

---

## Project Structure

citycyber_pos/
│
├── app.py               ← Flask backend (core engine)
├── db.py                ← Database layer (SQLite)
├── requirements.txt     ← Python dependencies
├── data.xlsx            ← Excel data source
│
├── templates/
│   └── index.html       ← POS dashboard UI
│
├── static/              ← Future CSS/JS
├── logs/
│   └── pos.log          ← Runtime logs

---

## Setup

1. Install Python (3.9+)
2. Install dependencies:

pip install -r requirements.txt

3. Run:

python app.py

---

## System Capabilities

- POS transaction engine
- Dynamic pricing control layer
- Udhaar (credit) ledger system
- Cashflow intelligence (upgrading)

---

## Goal

Convert this system into a high-control financial + operational engine.
